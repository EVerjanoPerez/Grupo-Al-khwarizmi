Repositorio compuesto por toda la información relacionada con el desarrollo de la aplicación de facturación para la empresa `TurbineH`. Este repositorio tiene la siguiente estructura:

1. **Documentación**: documentación técnica ligada al proyecto.
2. **Diagramas**: código que define los diferentes diagramas UML (casos de uso, secuencia...).
3. **Actas**: documentos en los que se recoge la información de las reuniones grupales y las decisiones tomadas en ellas.
4. **Planificación**: documentos relacionados con la planificación del proyecto.

## Herramientas y preferencias

### Estilo de ficheros

Como preferencia, los ficheros se guardarán en formato **Markdown** (`.md`) para que todo el equipo pueda visualizarlos en GitHub y modificarlos en cualquier momento. Cuando un documento se dé por finalizado tras revisarlo, se guardará también en formato `.pdf` para su posterior entrega y visualización.

En el caso de los diagramas UML, se utilizará como único formato válido el formato `.puml`, para su posterior visualización y modificación en la plataforma [PlantUML](https://plantuml.com/es/).
